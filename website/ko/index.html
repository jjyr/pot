01 / MACHINE POLICY & SRT SANDBOX

머신 실행 정책 및 SRT 네이티브 샌드박스

🛡️ Protected (보호 모드 · 기본값)신규 노드 기본값

명령은 기본적으로 SRT 네이티브 샌드박스(macOS Seatbelt 또는 Linux bubblewrap / seccomp) 내에서 실행됩니다. 현재 작업 워크스페이스만 쓰기 가능하며 개인 디렉터리, 런타임 설정, 무관한 소켓은 차단됩니다.

⚡ Trusted (호스트 실행 허용)명시적 활성화

노드 소유자가 명시적으로 전환한 경우에만 샌드박스를 건너뛰고 호스트에서 직접 실행합니다. 단, 명시적 deny_host 거부 규칙은 항상 우선 적용됩니다.

🚫 Blocked (긴급 전면 차단)긴급 차단 스위치

해당 머신에서 새로운 명령 실행이나 파일 수정을 즉시 차단하여 기존 승인 규칙을 덮어쓰며, 실행 중인 프로세스의 출력 읽기와 정리만 허용합니다.

02 / ZERO-WILDCARD APPROVALS

와일드카드 없는 명령 승인

샌드박스 외부 실행(request_unsandboxed: true)이 필요한 경우 이유를 제시하고 승인을 기다려야 합니다. 권한 규칙은 접두사 일치나 와일드카드를 지원하지 않습니다:

  • 전체 컨텍스트 바인딩영구 승인 규칙은 전체 명령 문자열, 정규화된 작업 디렉터리(cwd), 셸, 대화형 모드, 자격 증명 참조를 함께 바인딩합니다. npm test, npm install, npm test && curl은 모두 별개의 명령으로 취급됩니다.
  • 3가지 승인 범위allow_always(이 머신에서 해당 정확한 명령 조합 기억), allow_task(현재 작업 실행 중에만 유효), deny(거부)를 지원합니다.
  • 노드 간 권한 격리Agent Link 연결은 원격 노드에 로컬 실행 권한을 부여하지 않으며, 원격 Codex에 위임한 작업에서 승인이 필요하면 현재 대화로 요청이 전달됩니다.

03 / ENCRYPTED SECRETS & ON-DEMAND DECRYPTION

암호화 보관 및 사용 시점 메모리 복호화

KEYCHAIN / 0600

마스터 키와 데이터베이스 분리

암호화 마스터 키는 데이터베이스에 기록되지 않습니다. macOS에서는 시스템 Keychain(pot.control.secrets)에, Linux에서는 0600 권한의 독립 키 파일이나 POT_SECRET_KEY_FILE로 관리됩니다. 마스터 키를 안전하게 얻을 수 없으면 즉시 오류를 반환하며 평문으로 대체하지 않습니다.

AES-256-GCM

저장 시 암호화 (AES-256-GCM)

API 키와 OAuth 토큰은 SQLite에 기록되기 전 AES-256-GCM(매 쓰기마다 고유 96-bit Nonce 생성)으로 암호화됩니다. 설정 테이블과 관리 API는 불변의 secret_ref 참조만 다루며 평문을 반환하지 않습니다.

ON-DEMAND DECRYPT

사용 순간에만 메모리 복호화 및 주입

키 값은 평소 암호문으로만 보관되며 프롬프트, 채팅 기록, 로그에 포함되지 않습니다. 모델 요청을 보내거나 자격 증명 참조를 선언한 하위 프로세스를 시작하는 순간에만 제어 계층이 메모리에서 복호화하여 일시적 환경 변수로 주입하고 프로세스 종료 즉시 해제합니다.

RELEASES & SPECIFICATIONS릴리스 타임라인 및 오픈소스 엔지니어링 아키텍처

변경 로그 및 프로젝트 사양

MIT 라이선스로 제공되는 Pot은 지속형 어시스턴트, 백그라운드 Task 조율, Agent Link 연동, 샌드박스 보안을 지속적으로 개선합니다.

v0.0.4Latest Release

Homebrew 배포, PWA 콜드 스타트 복구 및 샌드박스 권한 강화

  • macOS 데스크톱 앱(brew install --cask jjyr/pot/pot) 및 독립 헤드리스 CLI(pot-cli) Homebrew 채널 추가.
  • Web UI / PWA 로컬 콜드 스타트 상태 복구 및 오프라인 캐시 전략 개선.
  • 샌드박스 권한 별칭 검증 수정 및 릴리스 E2E 자동 검증 강화.
v0.0.3Core & Agent Link

Agent Link 토폴로지 뷰, Codex 심층 연동 및 온보딩 개선

  • Agent Link 네트워크 토폴로지 상태 뷰 및 피어 재연결 복구 메커니즘 추가.
  • Codex 어댑터 강화: 독립 지속형 스레드, 병렬 작업 위임 및 원격 승인 전달 지원.
  • 첫 실행 어시스턴트 온보딩 개선(API 프로바이더 설정, 원격 Pot 연결, Codex 연동).
v0.0.2Models & Context

모델 디렉터리 자동 감지, 캐시 인지 압축 및 파일 워크스페이스

  • models.dev 공개 모델 디렉터리 및 로컬 캐시 통합, 연결 테스트와 모델 자동 감지 지원.
  • 프롬프트 캐시 수명 추정(기본 15분) 및 90% 컨텍스트 사전 압축 도입으로 장기 세션 토큰 비용 절감.
  • 어시스턴트별 파일 관리, 채팅 첨부 파일(이미지 / PDF) 및 인터랙티브 HTML 결과물 미리보기 지원.
v0.0.1Initial Architecture

지속형 어시스턴트 런타임, SRT 샌드박스 및 암호화 자격 증명 저장소

  • Go + 네이티브 데스크톱/Web UI 공유 아키텍처 구축, 지속형 세션 및 비동기 백그라운드 Task 분할 지원.
  • macOS Seatbelt 및 Linux bubblewrap 기반 SRT 샌드박스와 와일드카드 없는 명령 승인 엔진 구현.
  • AES-256-GCM 암호화 저장소 및 GitHub OAuth Device Flow 통합 내장.
