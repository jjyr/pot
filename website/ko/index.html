04 / 시작하기시작 방법 선택

Pot 시작하기

에이전트에게 설치를 맡기거나 데스크톱, Docker, Server를 선택하세요. Windows는 지원하지 않습니다.

소스 및 GitHub 가이드는 현재 저장소 접근 권한이 필요합니다. 권한이 없다면 프로젝트 관리자에게 사용 가능한 빌드를 요청하세요.

01

에이전트로 설치

이 영어 프롬프트를 에이전트에게 전달하세요. 공통 가이드를 읽고 환경과 설치 방법을 확인합니다.

Read https://github.com/jjyr/pot/blob/main/docs/install-with-agent.md and help me install and configure Pot on this computer.
설치 및 초기 설정 ↗
02

데스크톱 앱

macOS 26+ · Apple Silicon. Linux 네이티브 데스크톱은 Experimental입니다. 현재 소스 빌드를 사용하세요.

mise run prepare
mise run build
mise run open
데스크톱 설치 가이드 ↗
03

Docker

Linux amd64 / arm64. 아직 공개 이미지가 없습니다. 저장소에서 로컬 빌드 후 Compose로 시작하세요.

docker buildx build --platform linux/amd64 --load \
  --build-arg POT_APP_VERSION=0.1.0 \
  --build-arg POT_BUILD_REVISION="$(git rev-parse HEAD)" \
  -t pot-server:local .
docker compose -f docker/compose.yaml up -d --no-build
docker compose -f docker/compose.yaml exec pot pot access -browser-root /home/pot/.pot-web token
Docker 가이드 ↗
04

Server / Web UI

glibc Linux amd64 / arm64. 소스에서 실행하고 로컬 브라우저 또는 SSH 터널로 접속하세요.

mise run prepare
mise run build:go
.local/go/bin/pot serve -root "$HOME/.pot-node" -ui 127.0.0.1:17703
# 다른 터미널에서 로그인 토큰 가져오기:
.local/go/bin/pot access -root "$HOME/.pot-node" token
배포 및 운영 가이드 ↗

Git, mise, 새 checkout이 필요합니다. 저장소를 복제하고 mise install을 먼저 실행하세요. 기존 설치의 데이터 위치를 확인하세요.

예제 명령은 amd64용입니다. arm64는 가이드에 따라 플랫폼과 파일명을 변경하세요. 0.1.0 / local은 로컬 빌드 식별자입니다.
