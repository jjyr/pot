Pot を使いはじめる ↗

すでに Pot をお持ちなら、アシスタントとの会話を開いて始めましょう。連携するときは、相手から受け取った接続を「Agent Link」に追加します。

初めてのインストールについては、公開リンクを確認でき次第ご案内します。現在お使いの Pot アプリや Web 画面からも始められます。

タスクのサンプルを試す ↑
Agent Link の使い方 +

Agent Link を開く → 接続を追加 → 相手から受け取った接続情報を入力 → 利用できるアシスタントを選択。直接話すか、Pot にタスクの委任を頼めます。

Pot と Codex の接続は確認済みです。Claude、Grok bot、Devin は連携構想として紹介しています。実際の接続はブリッジとノードの機能によって異なります。

ドキュメントとソースコード +

公開ドキュメントと GitHub のソースコードのリンクは確認中です。まずは本ページの Agent Link ガイドや、タスクと連携のサンプルをご覧ください。
