オープンソースのパーソナル AI アシスタント

仕事の進行はアシスタントに。
目標と判断に集中できるように。

Pot は継続的な対話、バックグラウンドタスク、Agent 間の協働を組み合わせ、説明の繰り返しや作業の見守りを減らす働き方を探っています。

アシスタント
整理、実行、進行管理

Agent と働いていても、好みを伝え直し、進捗を確認し、次の作業を決めることには多くの注意が必要です。一つひとつの介入は小さくても、積み重なると実行の過程から離れられなくなります。

Pot は継続的に対話するアシスタントに、その進行を任せることを試みています。目標を話し合い、タスクを組み立て、進捗を追い、結果や判断が必要な問いを対話に持ち帰ります。

人は方向性、取捨選択、結果に注意を向け、アシスタントが日々の進行を少しずつ担います。

01

目標をすり合わせてから、タスクに任せる

対話で要件や取捨選択を話し合い、時間のかかる作業はバックグラウンドタスクに任せます。結果とファイルが元の対話に戻り、確認、修正、次の一歩を続けられます。

範囲を相談する
文書、インストール確認、スクリーンショットで、それぞれどこまで行うかを決めます。
タスクを追う
各タスクは識別子、状態、経過時間を保ち、実行中と待機中の仕事を確認できます。
戻った結果を確認する
ファイルが対話に戻ったら、修正を依頼したり、判断が必要な点から対応したりできます。

02

仕事ごとに、継続して担当するアシスタントを

開発、運用、資料整理にそれぞれアシスタントを置けます。独立した対話と指示で仕事ごとの背景を蓄積し、説明のやり直しを減らします。継続的な対話は、完全な記憶や正しい判断を保証するものではありません。

  • 開発とレビューリポジトリの規約、実装の選択、成果物について相談を続けます。
  • 資料整理出典、見解の違い、判断が必要な点を残し、次のまとめにつなげます。
  • 日々の運用環境、定期確認、問題への対応に関する背景を蓄積します。

03

その先の仕事を組み立てる手段を

タスクが実行を担い、スケジュールや通知がきっかけになり、Agent Link が他の Agent とつなぎます。アシスタントは次の仕事を組み立て、進捗と結果を対話に持ち帰れます。

Agent Link は Pot、Codex、Antigravity への接続に対応し、異なる環境のアシスタントが対話やタスクで協働できます。

01 / SYSTEM SANDBOX & POLICY

コマンドは標準でサンドボックス内で実行

🛡️ 保護モード（Protected）新規ノードの既定

保護モードでは macOS Seatbelt または Linux bubblewrap を既定で使います。ワークスペースは書き込み可能、必要なツールは読み取り専用で、無関係な個人ファイルや制御インターフェースは制限されます。ホスト実行の例外にはポリシーと許可が適用されます。

⚡ 信頼モード（Trusted）明示的な有効化

特定のノードでマシン上の直接実行が必要な場合は手動で切り替え可能。明示的な拒否ルール（deny_host）は引き続きブロックされます。

🚫 停止モード（Blocked）緊急停止スイッチ

ワンクリックで新しいコマンド実行やファイル変更を停止し、既存プロセスの出力確認と後片付けのみを許可します。

02 / HOST EXECUTION APPROVAL

サンドボックス外の操作はあなたが承認

ローカル SSH での Git push など、サンドボックス外の環境が必要な場合、アシスタントは理由を説明して承認を待ちます：

  • コマンド単位で個別に確認許可は実行コマンドと作業ディレクトリに厳密に紐づき（npm test と npm install は別確認）、他のコマンドに流用されません。
  • 有効範囲を選択可能「このタスクのみ許可」（完了時に失効）、「このコマンドを常に許可」、または「拒否」を選べます。
  • デバイスごとに権限を分離Agent Link で接続する Agent は独自の権限を保ちます。明示的に委派した Codex タスクは人の承認待ち要求を返せますが、Antigravity のヘッドレスモードは対話的な承認を転送できません。

03 / SECRET ENCRYPTION & IN-MEMORY DECRYPTION

鍵は暗号化して保存し、使用時のみ復号

KEYCHAIN / 0600

マスターキーを分離保管

暗号化用のマスターキーは DB に保存されず、macOS では Keychain、Linux では所有者のみ読める（0600）鍵ファイルに保管されます。

AES-256-GCM

データベース内では常に暗号文

API キーやトークンは AES-256-GCM で暗号化してからローカル DB に保存。設定画面や API は参照 ID のみを扱います。

IN-MEMORY USE

呼び出し時のみメモリ上で復号

モデルへのリクエストや認証情報の注入時に、必要に応じて鍵を復号します。UI とツールは認証情報の ID を参照します。許可されたプロセスは注入された情報にアクセスできるため、ツールと実行範囲を慎重に選んでください。

Pot 0.0.4 — Offline startup, chat recovery and local drafts

  • Reopen an installed PWA from its complete cached shell, assistant directory, conversations, reading position and drafts while runtime checks run in the background.
  • Restore one local draft per assistant (including text, references and original attachment files) and continue interrupted turns from the composer button.
  • Recover stalled browser chat streams and cancelled access probes; unify local file delivery, add lifecycle notifications and optional PWA Web Push.
  • Repair native update simulation discovery and preserve writable Task workspaces when the Runtime state root uses a filesystem alias.
v0.0.3 ↗2026-10-26

Pot v0.0.3 — Conversation continuity, committed data reads and update discovery

  • Chat and Task views share a conversation list controller that preserves reading position and stable message anchors while scrolling, refreshing, and loading older history.
  • Frontend views render committed local data through shared repositories and bounded queries, revoking stale menu actions before execution.
  • Updates are easier to discover from shared navigation and Settings, with migration lineage validation and transactional database migration batches.

Pot 0.0.2 — Assistant setup, Agent connections, task continuity and desktop updates

  • Create assistants directly on existing Runtime connections with guided Codex and Antigravity setup, and add Antigravity Agent Link support.

  • Repair the native macOS App update lifecycle and add an independent macOS Homebrew CLI Formula (pot-cli).
