Instalación y configuración inicial ↗

macOS

macOS

macOS 26+ · Apple Silicon

Homebrew

Añade este repositorio como tap de Homebrew y ejecuta:

brew tap jjyr/pot https://github.com/jjyr/pot.git
brew install --cask jjyr/pot/pot
Instalación con Homebrew y primer inicio ↗

La instalación estará disponible tras la primera versión de macOS y la integración del cask; Homebrew conserva las comprobaciones de seguridad del primer inicio.

Linux

Linux .deb Experimental

Escritorio nativo · Debian / Ubuntu · amd64

Descargar .deb ↗Guía de instalación en Linux ↗

Las descargas abren las versiones oficiales; los paquetes están pendientes de su primera publicación.

Web UI

Ejecuta en tu ordenador o servidor y úsalo desde el navegador.

Ejecutar el servidor directamente

Descarga una versión y ejecuta el servidor directamente.

Descargar Web UI / Server ↗

Elige un archivo pot para Linux amd64 / arm64.

Comando de inicio

Extrae el archivo de tu plataforma y ejecuta desde su directorio bin:

./pot serve -root "$HOME/.pot-node" -ui 127.0.0.1:17703
