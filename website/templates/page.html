01 / SYSTEM SANDBOX & POLICY

命令默认在沙箱中运行

🛡️ 受保护模式（Protected）新节点默认

日常命令默认在系统自带的沙箱（macOS Seatbelt 或 Linux bubblewrap）里运行。助手只能读写当前任务的工作目录，无法触碰你的个人文件夹或系统设置。

⚡ 信任模式（Trusted）显式开启

如果你需要让某个节点直接在机器上运行命令，可以手动切换到信任模式；明确禁止的命令规则（deny_host）依然会被拦截。

🚫 停用模式（Blocked）紧急熔断

一键暂停该节点执行任何新命令或修改文件，只允许查看已有进程的输出和清理收尾。

02 / HOST EXECUTION APPROVAL

超出沙箱的操作，由你拍板

当任务确实需要用到沙箱外的环境（比如调用本机 SSH 推送代码）时，助手会在对话里说明原因，等你确认后再继续：

  • 逐条确认具体命令每次授权只针对当前这条命令和所在目录（比如 npm test 和 npm install 分开确认），不会被其他命令顺带借用。
  • 按需选择有效期可以选择「仅本次任务允许」（任务做完即收回）、「始终允许这条命令」，或者直接拒绝。
  • 不同设备权限独立通过 Agent Link 连接其他机器的 Agent 时，不会直接开放本机权限；远端需要确认的操作也会发回当前对话询问你。

03 / SECRET ENCRYPTION & IN-MEMORY DECRYPTION

密钥加密保存，仅在使用时解密

KEYCHAIN / 0600

主密钥分开保管

用来加解密的主密钥不会写进数据库。macOS 上保存在系统钥匙串（Keychain）里，Linux 上保存在仅当前用户可读（0600）的独立密钥文件中。

AES-256-GCM

平时始终密文存放

你填写的 API Key 和第三方登录令牌都会用 AES-256-GCM 加密后再存入本地数据库。日常配置和界面只会引用密文编号，不会直接读取明文。

IN-MEMORY USE

仅在调用时临时解密

密钥不会进入对话上下文或日志文件。只有在真正向模型发起请求、或启动需要该凭据的子进程那一刻，才会在内存中临时解密使用，用完立即释放。
