# Shared App/Mobile chat validation — 2026-10-07

## Baseline and implementation

Native baseline: commit `122aa47599a255d4160b76835424635da828e02e`, the mobile
owner pilot before extraction. The baseline App binary was built and saved before
source changes. Refactored App ran in the same isolated test bundle, with the same
1080 × 760 GPUI window, fixture data, language, display scaling and App preferences.
The comparison does not use screenshots from a different product revision.

`pot-ui` now owns the actual GPUI message tree, Markdown, theme tokens,
locale-explicit catalogs and chat request/receipt/draft policy. App and Mobile
both call it. Browser fetch and native ureq remain separate adapters. The Swift
composer, native navigation, running-task summary and Finder extension remain in
App; whole Tasks/Sandbox/Usage pages have not been migrated in this first phase.

## Browser integration

UI fixture. Authentication was simulated in this fixture; it does not replace
The current browser authentication contract is in [Browser access](../mobile-access.md).

- The same representative transcript rendered Markdown, user/assistant styling,
  tool controls and visible touch copy icons. Icons are embedded, without CDN.
- An actual GPUI composer/button send encountered an injected first-POST failure.
  Explicit retry sent the same UUID; two attempts produced exactly one canonical

## Repeatable setup

`scripts/tests/shared-ui-fixture.py` serves only synthetic state on loopback and
refuses to replace a non-fixture native endpoint. Use a disposable App root:

```sh
mise exec -- python scripts/tests/shared-ui-fixture.py \
  --root .local/ui-check --port 17903 --mobile-assets crates/web-ui/dist
# Launch an isolated App build with POT_LOCAL_ROOT pointing at that absolute root.
# Browser UI fixture: http://localhost:17903/ (localhost secure-context exception).
```

Build/save the baseline binary before extraction, then replace only the test
bundle binary. Keep window dimensions, transcript and appearance fixed. Compare
raw screenshots and inspect all changed regions; cursor/animation differences
must not conceal layout changes. Real deployed access still requires trusted HTTPS.
