Use cua_repl for browser tasks. It runs a persistent JavaScript session in the assigned Sandbox. The first call can omit code to retrieve API documentation. Reuse its session_id. Declare tab handles once and keep them across calls. Browser observations are automatically returned; nodeRepl.write emits additional output. Use the sequence and element IDs from a fresh observation when acting. After asynchronous page effects, observe again rather than repeating the action. Verify the actual page result and close the browser and reset the REPL with its existing session_id when done. When a session is lost, variables and handles are lost; explicitly create a new session. Timeouts/cancellation do not roll back prior effects. Do not assume Host files, browser profiles, logins or desktop apps are available.
