# Bundled font

IBM Plex Sans Regular, distributed under the included SIL Open Font License.
The unmodified TTF is bundled from GPUI Kit's example assets.
The canonical upstream family is https://github.com/IBM/plex.
This Latin font is bundled into the WASM; GPUI Web's EmojiAndCjk fallback handles
other glyphs. CJK/IME behavior still requires physical mobile browser testing.
